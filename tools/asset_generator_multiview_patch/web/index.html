EDITABLE PIPELINE Re-run a stage without regenerating geometry

Review stages are human gates. Processing preserves rigged input; rig creation, retargeting, overlap analysis and automatic part identification remain unsupported.

Balanced optimization remeshes static surfaces and simplifies rigged meshes. Retopology rebuilds the surface with QuadriFlow, then transfers materials and skin weights. Shape guards retain the source if a reduction damages it; animation and anatomy still need visual review.

Original geometry is retained. Optimization produces a derived runtime mesh; the report records achieved triangles, surface error and any rejected attempts. Separate static LODs remain available for review.

BACKEND CAPABILITIES

Material & effect variants

Set material_variant in the configuration to adjust unlinked roughness or emission on an existing candidate. Re-run Blender without reconstructing the geometry. This does not paint new textures.

Equipment & attachment

Set attachment for a named socket in the Blender source. For Godot rig testing, select an equipment asset with equipment_asset and specify weapon_attachment. These positions must be checked against the hand in motion.

VISUAL ACCEPTANCE Technical validity is a separate result
UNRESOLVED DEFECTS

Inspect the mesh itself.

Use clay and wireframe views to check geometry independently of texture. Check unseen surfaces, fused equipment and material lighting.

Deformation review

For rigged assets, inspect shoulders, elbows, hips and knees through every required clip. Check armor and cloth clipping, weapon alignment and foot sliding.

Acceptance means your decision

Passing an export check never accepts an asset. The manifest records your checklist, defects, overrides and the exact reviewed runtime hash.
